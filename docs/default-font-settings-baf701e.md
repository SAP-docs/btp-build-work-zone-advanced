# Default Font Settings

You can change the default font settings for texts in workpages, blogs, wikis, and knowledge base articles.

To enable users to use their own custom fonts do the following:

1.  In the Administration Console, go to *Theming and Branding* and select *Default Font Settings*.

2.  From here you can select from the list of Standard fonts or you can select the Custom font option. In this case you would need to upload the custom font in `.woff` format.

3.  To change the default font size, you can select the supported sizes from the relative dropdown lists for the *Text* widget, workpage section title, and the workpage cell title. At runtime, the user is then able to select their custom font style and size using the dropdown lists in the text editor, or at the top of the section title or cell title.

4.  Save your changes.
