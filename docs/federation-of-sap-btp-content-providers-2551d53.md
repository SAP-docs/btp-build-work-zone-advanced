# Federation of SAP BTP Content Providers

An overview of the SAP BTP content providers.



SAP BTP content providers are content providers that are located in the SAP BTP environment. You don't need to create a content provider for content on SAP BTP - for example for HTML apps or plugins, the content provider is created automatically when subscribing to the service.

The following SAP BTP content providers are available:

-   HTML5 Apps \(recommended\) - created automatically when you subscribe to SAP Build Work Zone, advanced edition.

-   Launchpad Modules \(created in the SAP Cloud Portal service by the developers of the app solution\):

    -   Custom solutions

    -   SAP solutions, such as Real Estate or Excise Duty



You can integrate apps and shell plugins from these providers into a SAP Build Work Zone, advanced edition site.

> ### Note:  
> The terms 'content' and 'content items' are used to refer to apps and shell plugins together.

In the subtopics that follow, we describe the characteristics of each content provider, and the process of integrating apps and shell plugins into the SAP Build Work Zone, advanced edition.
