# Getting Support

Before you report an incident, check the platform status, your tool versions and announcements about system maintenance schedules.



For more information, [Getting Support](https://help.sap.com/docs/BTP/65de2977205c403bbc107264b8eccf4b/5dd739823b824b539eee47b7860a00be.html).

For information about the planned release schedule, see SAP Note [3303878](https://me.sap.com/notes/3303878).
