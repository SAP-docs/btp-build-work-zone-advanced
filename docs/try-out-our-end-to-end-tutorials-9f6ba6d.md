# Try Out Our End-to-End Tutorials

In this topic, you’ll find two groups of end-to-end tutorials for SAP Build Work Zone, advanced edition.



The tutorials guide you through a scenario that covers a typical way you would design your site. The tutorials are written in a way to help you get a basic understanding of how to use the product and include screenshots to help you along the way.

Due to the fact that SAP Build Work Zone, advanced edition is not available on a trial account, you need to already have done all the onboarding steps. For more information, see [Onboarding to SAP Build Work Zone, advanced edition](onboarding-to-sap-build-work-zone-advanced-edition-f8c6eab.md).



## Let's get started!

In this first group of tutorials, you'll design a home page for your site and you'll create a workspace. You'll then add widgets and apps that you will configure to them.
