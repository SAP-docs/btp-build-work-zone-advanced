# Enabling Statistical Data Collection

Use this SAP Cloud ALM option to monitor statistical data.



<a name="loioc51168e3bdc1487b968b9efb52bc621c__section_qxc_dtw_hgc"/>

## Overview

Real User Monitoring enables users to understand how often applications are executed and what the response times are.

Applications that can be activated are:

-   HTML5 apps from the HTML5 content provider

-   Locally created SAPUI5 applications \(in the Content Manager\)


For more information about the performance and usage metrics, see [Real User Monitoring - Scope and Content](https://support.sap.com/en/alm/sap-cloud-alm/operations/expert-portal/real-user-monitoring.html?anchorId=section_copy#section_copy).



<a name="loioc51168e3bdc1487b968b9efb52bc621c__section_rfw_2tw_hgc"/>

## Setup

To set up this feature, please follow the steps in this topic: [Real User Monitoring - Setup and Configuration](https://support.sap.com/en/alm/sap-cloud-alm/operations/expert-portal/real-user-monitoring/run-details.html).



<a name="loioc51168e3bdc1487b968b9efb52bc621c__section_lzx_45w_hgc"/>

## Enable the Collection Metrics

Once you've completed the set up, you need to enable this feature. For HTML5 apps and locally created HTML5 apps, go to the *Site Settings* screen and under *Services*, enable the *Statistical Data Collection*setting.
