# Action Widget

Use this widget to make commonly used action types more visible to workspace members.

By adding the action widget, you allow workspace members to select from a variety of commonly used action types. These actions might not be available elsewhere on the overview pages, or they might be used so often that they need a dedicated tile to be easily noticeable among other sections.

> ### Note:  
> You can only add one action widget to a workpage.

You can set the following details:

-   **Widget title:** Enter a name for the list of actions, or accept the default name *Actions*.

-   **Select actions:** By default, all actions are selected, but you can uncheck the ones that are not relevant for your workspace. They will not display in the tile. A minimum of one action must be enabled.

-   **Configure content destination folders:** The following actions, if selected, require you to specify a destination folder or location in which to place the content. If you don't specify a folder or location then the defaults that display in the dropdown menus for each action are applied.

    -   Ask a Question

    -   Add an Idea

    -   Add a Discussion

    -   Upload a File

    -   Record a Video

    -   Add a Blog

    -   Add a Wiki

    -   Add a Task

    -   Add a Playlist



> ### Note:  
> If there is an *Actions* widget on a workspace workpage with a forum topic action enabled, when the forum type is changed by the workspace administrator, the forum topic action will be removed from the *Actions* widget. A notification is sent to the other workspace administrator\(s\) when the forum type is changed, affecting the *Actions* widget. It's up to the workspace administrator to take corrective action \(for example, change the forum type in the *Actions* widget\), if necessary.
