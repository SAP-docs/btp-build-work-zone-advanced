# How to Manage Translations

Learn how to manage translations for your site.



<a name="loio2d4c05a9be654df8b9df2186d9d40cd4__section_ncs_2rl_bgc"/>

## Overview

There are three different levels of managing translations.


<table>
<tr>
<th valign="top">

Level

</th>
<th valign="top">

More information

</th>
</tr>
<tr>
<td valign="top">

Site

</td>
<td valign="top">

From the *Site Settings* screen, select the languages that you want to expose to the users of the site. Once you've done this, then the languages that you selected, are available for end users to select from the *User Actions Menu* \> *Settings* screen.

For more information, see [Site Settings](site-settings-ca74965.md) under *User Capabilites*.

</td>
</tr>
<tr>
<td valign="top">

Workpages

</td>
<td valign="top">

From the workpage editor, you can translate the titles of widgets and captions of widgets as well as texts that were created using the *Text* widget.

For more information, see [How to Translate Workpage Texts and Titles](how-to-translate-workpage-texts-and-titles-cc6838c.md).

</td>
</tr>
<tr>
<td valign="top">

Content

</td>
<td valign="top">

You can translate the content in your workspace by bundling translations for a specific content type.

For more information, see [How to Translate Your Content](how-to-translate-your-content-09d5b21.md).

</td>
</tr>
</table>
