# What's New

Find information about the new, changed, and deprecated features in SAP Build Work Zone, advanced edition.



## SAP Build Work Zone, advanced edition

There are two types of releases in SAP Build Work Zone, advanced edition, a preview release that is available on systems that have been configured as preview systems, and a productive release that is available on all systems.



### Preview Release

Systems that have the *Enable Preview Release* setting enabled on the *Overview* page of the Admin Console, are updated with new features one release before the productive release.

> ### Note:  
> -   Preview features represent product development expectations only and are not a delivery commitment. These features might not be delivered in the indicated time frame, or at all. Customers should base their purchasing, administrative, and configuration decisions solely on functionality that is currently available.
> -   Once enabled, this setting can't be disabled on a system.

The availability date of the new features on the preview systems and the information about how to use them can be found in [What's New on Preview Systems](what-s-new-on-preview-systems-10a3b67.md).



### Productive Release

The release to production typically takes place 4 weeks after the release to preview.

Systems that have the *Enable Preview Release* setting disabled, will be updated with the new features at this time.

For more information about new features that reach production, refer to the What's New Viewer: [What's New in SAP Build Work Zone, advanced edition](https://help.sap.com/whats-new/cf0cb2cb149647329b5d02aa96303f56?Component=SAP%20Build%20Work%20Zone,%20advanced%20edition&locale=en-US).

> ### Note:  
> The What's New Viewer is updated one week before the release to production, and the items there are marked with a *Preview* label until the release date.
