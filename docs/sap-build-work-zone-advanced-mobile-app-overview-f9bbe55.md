# SAP Build Work Zone Advanced Mobile App: Overview

The SAP Build Work Zone Advanced mobile app enables users to access their workspaces when they are on the go, and use common features of SAP Build Work Zone, advanced edition.

> ### Note:  
> The SAP Build Work Zone, advanced edition mobile app is in maintenance mode. It is highly recommended to switch to the Joule Work mobile app. For more information, see [Mobile Apps](mobile-apps-274e234.md).

Users can not only access all the workspaces that they are assigned to - they can also display different types of content, as well as perform workspace actions directly from their mobile device.



Users download and set up the SAP Build Work Zone Advanced app themselves. The app is available on the Apple App Store and Google Play Store. Users can also install this mobile app by opening the User Actions menu under their avatar, selecting*Settings*, and from the *Mobile Application* setting, they can scan the QR code.
