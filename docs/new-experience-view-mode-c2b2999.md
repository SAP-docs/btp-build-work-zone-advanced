# New Experience View Mode

Learn more about the Spaces and Pages - New Experience view mode of a site.



## What is the New Experience View Mode?

The Spaces and Pages - New Experience view mode is the latest view mode available for sites. It includes the following key capabilities:

-   Creation of local spaces and pages that are rendered side-by-side with federated spaces and pages. Unlike the federated content that is read-only, local spaces and pages are fully customizable.
-   New experience pages have a grid-based layout which you can design by adding sections and columns, change tile size, and more.
-   Support for cards - in addition to tiles, you can add cards as app visualizations. Cards have a rich user interface and they allow users to view and interact with data without leaving the site.
