# Integration with SAP Service Cloud Version 2

Using SAP Build Work Zone, advanced edition, administrators can integrate Knowledge Base with SAP Service Cloud Version 2.



With SAP Service Cloud Version 2, service agents can access customer information via collaboration tools and Knowledge Base, and quickly address customer issues. For more information about SAP Service Cloud Version 2, see [Product page](https://help.sap.com/docs/CX_NG_SVC).

Knowledge Base is a repository of articles providing solutions to previous issues that agents use to resolve a current customer issue. Knowledge Base is a separate system from Service Cloud version 2, which appears in the side panel \(as a widget\) of the Agent Desktop.

To create a Knowledge Base widget, administrators need to perform several steps in SAP Build Work Zone, advanced edition. For more information about the integration flow, see [Knowledge Base](https://help.sap.com/docs/CX_NG_SVC/56436b4e8fa84dc8b4408c7795a012c4/6ebfb976b88244b2b3d7f2c8b0c78426.html).
