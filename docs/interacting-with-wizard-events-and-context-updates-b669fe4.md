# Interacting with Wizard Events and Context Updates

Card developers can configure their cards to interact with a wizard on a workpage.



Workspace administrators can create wizards to help users complete step-by-step processes. The wizards can contain one or multiple stages, each with steps and contextual information that assists the users to complete the steps. In addition, workspace administrators can add widgets and cards to the wizard steps. When a card/widget is added to a step, the step will only be marked as complete when the required user input is added to the card/widget.

As a card developer, you can interact with the wizard to leverage wizard events and context updates. For example, you can subscribe to the “Next Step” event to trigger data validation and then submit the content to the server.

A full Developer Guide with sample cards is available for you in Github. For more information, see [Wizard Developer Guide](https://github.com/SAP-samples/build-workzone-integration/tree/main/advanced/wizard).
