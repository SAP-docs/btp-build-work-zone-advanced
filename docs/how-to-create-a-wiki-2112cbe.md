# How to Create a Wiki

You can create a wiki page from a workspace that you're a member of or directly from your profile page.

Create a wiki page in one of the following ways:


<table>
<tr>
<td valign="top">

In the workspace

</td>
<td valign="top">

1.  Go to the *Content* list of the workspace.

2.  From the User Actions menu, select User Profile.




</td>
</tr>
<tr>
<td valign="top">

From your profile page

</td>
<td valign="top">

1.  From the *\+ Create* dropdown menu, select *Wiki Page*.

2.  Choose the *Wiki Pages* tab.

3.  Choose *\+ Create a Wiki Page*.




</td>
</tr>
</table>

Once you've created the wiki you can save it as a draft or publish it. When you publish a wiki page, you can set permissions in the *Publish* dialog. For more information, see [Content Permissions](content-permissions-8f317cb.md).

> ### Note:  
> Once you've created your wiki page, a default thumbnail image is auto generated. A thumbnail image enables you to personalize your wiki so that others can quickly identify them. For more information about how to use thumbnails, see [How to Add Thumbnails to Your Content](how-to-add-thumbnails-to-your-content-0174ab7.md).

For more information, see[About Wiki Pages](about-wiki-pages-3161f35.md).
