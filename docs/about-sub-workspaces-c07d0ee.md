# About Sub-Workspaces

Sub-workspaces can contain a subset of the members of the parent workspace. This allows the members of the sub-workspace to have a distinct environment in which they can work together.

To create a sub-workspace, you first have to add a *Sub-Workspaces* navigation tab to the workspace.

**Points to remember:**

-   Sub-workspace members must be members of the parent workspace. If a member of the sub-workspace is removed from the main workspace, they are also removed from the sub-workspace.

-   Inviting a user to a sub-workspace also invites them to the parent workspace if they aren’t already a member.

-   If the parent workspace is not accessible by external users \(in other words the *External users can access this workspace and be invited as members.* option in the parent workspace is disabled\), then external users can't access any of the sub-workspaces either.

    If there are already external users in the parent workspace, and they are removed, then when next you edit the sub-workspace, the external users will also be removed.

-   Only administrators of the parent workspace can create sub-workspaces. They can delegate the administration of sub-workspaces by promoting other members of the sub-workspace to sub-workspace administrators.


> ### Note:  
> When you create a sub-workspace, you can select a workspace template and configure the workspace in the same way as you would configure a parent workspace.
> 
> For more information, see [How to Create a Workspace](how-to-create-a-workspace-770f1b0.md).
