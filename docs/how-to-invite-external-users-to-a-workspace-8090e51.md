# How to Invite External Users to a Workspace

Workspace administrators can invite external users to their public and private workspaces.



## Overview

Users who are not employees of the company are referred to as external users. Depending on the company settings, it may be possible to invite external users to your private or public workspace.

You can only invite an external user that already exists in the company external user list. If the user doesn't exist in the external user list, you will receive an error upon sending the invitation email.

If you choose to invite an external user to your workspace, make sure that you don't have any confidential or internal information on the workspace. To help you remember not to add internal information, as soon as you invite an external user, a warning icon will be displayed on the workspace to indicate that the workspace is visible to external users.

## Procedure

1.  In the workspace settings make sure that the option *Allow external users to access this workspace and be invited as members* is selected. You can choose this option when you create a workspace or when you edit an existing workspace, as long as the company workspace settings allow this.
2.  Click +Invite at the top of the workspace.
3.  In the *Invite Workspace Members* screen, enter the external user email, a personal message \(optional\), and click *Send*.

    If the external user email doesn't exist in the external users list \(available to company administrators in the Admin Console\), the following error is displayed: "Unknown e-mail address".
