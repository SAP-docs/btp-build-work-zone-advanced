# Updating a Workspace Template

Update a workspace template using SAP Business Application Studio.



<a name="loio569df2737c384f2485260b1bd18c44fc__steps_dgn_5f5_xkb"/>

## Procedure

1.  Launch SAP Business Application Studio and navigate to the dev space where you created the workspace template.

2.  To edit the `manifest.json` file, navigate to the project that contains the required workspace template. From the context menu, choose *Workspace Template: Edit*. You can also directly open the `manifest.json` file in the code editor.

3.  You can add or edit resource files under the template folder as per your requirements.
