# App Configuration Properties for SAP SuccessFactors Deep Links

Configuration properties that are required for configuring an app for SAP SuccessFactors deep links



To configure an app for SAP SuccessFactors deep links, use the following properties:


<table>
<tr>
<th valign="top">

Property

</th>
<th valign="top">

Value

</th>
</tr>
<tr>
<td valign="top">

*Open App*

</td>
<td valign="top">

In a new tab.

</td>
</tr>
<tr>
<td valign="top">

*System*

</td>
<td valign="top">

Select the name of the destination you created.

For more information, see [Direct Access to SAP SuccessFactors Deep Links](direct-access-to-sap-successfactors-deep-links-e62af55.md).

</td>
</tr>
<tr>
<td valign="top">

*App UI Technology*

</td>
<td valign="top">

Dynamic URL

</td>
</tr>
<tr>
<td valign="top">

*Relative Path to App*

</td>
<td valign="top">

Specify the relevant deep link path. For more information, see [List of SAP SuccessFactors Deep Links](https://help.sap.com/viewer/5c6733335c434d6f81210378bbea6405/LATEST/en-US/6d149a28c77a4f3da92fdc0f5dde9079.html).

</td>
</tr>
<tr>
<td valign="top">

*URL Parameter*

</td>
<td valign="top">

-   Name: `sap-company`

-   Value: `<SAP SuccessFactors Company ID>`




</td>
</tr>
</table>
