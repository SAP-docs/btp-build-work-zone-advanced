# Establish Trust

Configure a trust between SAP BTP and the Identity Authentication service to enable user authentication.



To enable SSO, you need to make sure that SAP Build Work Zone, advanced edition and all the embedded applications have a trust with the same Identity Authentication tenant.

The trust is required in two levels:

-   Subaccount level establish trust \(OIDC\).
-   Direct trust with Identity Authentication.

The trust is configured during onboarding to SAP Build Work Zone, advanced edition, therefore no further actions are required to set up trust.
