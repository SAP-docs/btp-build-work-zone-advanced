# Previewing the Latest SAPUI5 Version

Administrators can preview the latest SAPUI5 version on selected sites for validation purposes.



SAPUI5 usually releases a new version every 4 weeks: [SAPUI5 Release Timeline](https://me.sap.com/notes/3504933).

To allow you to test the new SAPUI5 version before it is consumed by all productive sites, you can enable the site setting *Preview SAPUI5 Latest Version* on selected non-productive sites, and test the latest version for a period of two weeks. Two weeks after the SAPUI5 release date, this version will become active.

A site that has the preview option enabled for it, will have a *Preview Latest Version* label added to its site tile in the Site Directory.

> ### Tip:  
> It's recommended to review the SAPUI5 release schedule in advance and plan your validation period accordingly.

> ### Note:  
> You can create dedicated sites for development, testing, and validation on different subaccounts, transport site specific content to the validation site, and enable the preview SAPUI5 site setting there.
