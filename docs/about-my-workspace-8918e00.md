# About My Workspace

*My Workspace* is a personal workspace. If the feature is enabled, all users see the same default *My Workspace* and can modify it to suit their personal requirements with all enabled cards and widgets in the system.



All users can create their own workspace. However, there are some limitations as to what you can use it for and what you can add to it.

-   Only you can see your *My Workspace*. You can't share it with others or add members to it.

-   You can add documents, apps, and information that you use on a daily basis but you can't share the content with your colleagues or teams using feeds.

-   Some widgets can't be added to *My Workspace* - for example, Forums or Events.


*My Workspace* includes the following default tabs:

-   *Overview* - this is where you can add your favourite content, tools, and apps and design it using the page designer tool.

    For more information, see [How to Use the Workpage Editor](how-to-use-the-workpage-editor-9164929.md).

-   *Content* - this is where you can create your own folder structure and store files that you upload. You can also add other types of content, such as links, wiki pages, or blog posts.

    For more information, see [About the Different Types of Content](about-the-different-types-of-content-27ed69c.md).

-   *Trash* - this is where you can find content items that you’ve deleted. You can restore the items or delete them permanently.
