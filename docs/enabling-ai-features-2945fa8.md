# Enabling AI Features

SAP Build Work Zone, advanced edition offers AI-based capabilities such as text generation and text summarization.



<a name="loio2945fa8f3fed44fcbb82d37e5008175e__section_vd4_3g5_zfc"/>

## About the AI Promotional Model

The following AI-based features are available in workpages: content generation, content summarization, and comment generation. These features are available for a limited period until **30th June 2026** and are offered as a promotional model that allows you to use it without charge.

Users are entitled to trigger up to 100,000 requests per calendar month across all SAP Build Work Zone, advanced edition instances within your SAP BTP global account. If the monthly requests exceed the limit in this global account, users will receive a message accordingly. The following month the quota will be reset, and users can continue to use the features.

Once the promotional period ends, you can continue using the AI features under the commercial model that’s in place. If you don't enable the commercial model after the promotional period ends, the feature is automatically disabled.



<a name="loio2945fa8f3fed44fcbb82d37e5008175e__section_h3y_s35_zfc"/>

## Availability

The AI capabilities require an integration with SAP AI Core, which is available on the following data centers:

-   AWS: Australia \(Sydney\), Brazil \(São Paulo\), Europe \(Frankfurt\), Europe \(Frankfurt\) EU Access, Japan \(Tokyo\), Singapore, US East \(VA\).
-   Microsoft Azure: Australia \(Sydney\), Europe \(Netherlands\), US East \(VA\).
-   Google Cloud: Australia Southeast \(Sydney\), Europe \(Frankfurt\), India \(Mumbai\), KSA \(Dammam – KSA Regulated Customers\), US Central \(IA\).



<a name="loio2945fa8f3fed44fcbb82d37e5008175e__section_ibl_xl3_k2c"/>

## Configuration

In the Administration Console, go to *Feature Enablement* \> *Features*.

1.  Under *Feature Management*, select the AI features that you wish to enable.
2.  A document opens that includes terms and conditions for using the AI features. You need to accept or decline these terms.

For more information about how to use these features in a workpage, see [How to Use AI Features to Create Content](how-to-use-ai-features-to-create-content-f950f0d.md).
