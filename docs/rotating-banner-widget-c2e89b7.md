# Rotating Banner Widget

This widget allows you to create a carousel. With a slider, you can display slides that contain the information you want to share.



The rotating banner widget can include up to 10 slides. You can either click the next or previous buttons to move through the slides or let the slides in the banner automatically advance to the next one in the sequence.

> ### Note:  
> If the rotating banner has been added to a workpage that is part of the site menu, the content that was added to the rotating banner can be referenced from any public or private workspace. Users can view the all the content in the rotating banner depending on their access permissions for the content.

You can upload a new image or choose an existing one.

Supported file types are JPEG, GIF, and PNG. Maximum size of images is 20 megabytes.

You can zoom in or zoom out using the image scale bar or you can click and drag the image up and down within the box. You can also use the *Scale to fit* icon at the top right side to center or scale the image.

**Dimensions:**

-   **Height:** minimum height is 270 pixels and maximum height is 500 pixels.

-   **Width:**
    -   For a 4-column banner is 1180 pixels

    -   For a 3-column banner is 883 pixels

    -   For a 2-column banner is 585 pixels

    -   For a single column banner is 288 pixels



> ### Note:  
> -   When added, images are automatically cropped and resized. You can then manually scale each image. As you resize the height for one image, the other slides in the banner will also apply the new image height dimension.
> 
> -   For mobile devices and responsive view, the rotating banner widget behaves similar to the image widget where images are scaled to fit the width of the device, preserving the aspect ratio, and without cropping. Any titles or description are also scaled to fit the device width, and truncated where necessary to fit the underlying image.

> ### Tip:  
> We recommend that all images used for a rotating banner widget have the same image dimension \(height and width\). For example, avoid mixing extremely wide and tall images. Multiple heights and whitespace are not permitted.

You can now click *\+ Slide* on the left side of the dialog box to add additional slides.

When you're done, you can reorder the slides on the left side of the dialog box by selecting the 3 dots next to each slide and draging it to the correct position.

To delete a slide from the banner, click the *x* next to the slide in the left panel of the dialog box.

Dont'forget to *Save* your settings!
