# Transport Selected Content

Administrators can select in the Content Manager specific content items to transport via the SAP Cloud Transport Management service.



## Overview

In the Content Manager, you select the specific content items that will be transported using SAP Cloud Transport Management. These content items are transported together with any related content items.

For more information, see [Before Transporting Content - Important Rules and Guidelines](before-transporting-content-important-rules-and-guidelines-4d3f192.md).

> ### Note:  
> Access the Content Manager as follows:
> 
> 1.  From the *Administration Console* menu, go to *External Integrations* \> *Business Content*.
> 
> 2.  Click *Content Manager*.



<a name="loioe809cb3866a64692a539f4c74430cd86__section_mvz_ybp_5qb"/>

## Procedure

1.  In the Content Manager, select the content items that you want to export.

    > ### Note:  
    > Toggle the *Selected* button at the top, to toggle between viewing only the selected items or viewing all the items in the list.

2.  Click the <span class="SAP-icons-V5"></span> \(Export selected content items using SAP Cloud Transport Management System \(CTMS\)\) icon above the list on the right.

3.  In the dialog that opens, review the list of selected items and click *Transport*.


The selected content items, together with their related content items, are transported from the source system to the target system.
