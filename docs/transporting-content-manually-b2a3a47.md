# Transporting Content Manually

Administrators can transport content between Dev, Test, and Production environments.



<a name="loiob2a3a47749c741faac8fccd1ed4d22f3__section_pfdb_q1l_3dc_jmb"/>

## Overview

Administrators can export content from a source environment, such as Dev, and import it to a target environment, such as Test. This is done manually by exporting \(downloading\) the content from the source environment and then importing \(uploading\) the content to the target environment.

For information about transport rules and guidelines, see [Before Transporting Content - Important Rules and Guidelines](before-transporting-content-important-rules-and-guidelines-4d3f192.md).

> ### Note:  
> Note that in SAP Build Work Zone, advanced edition and SAP SuccessFactors Work Zone, you can only import selected content items; it is not possible to import a site and its content.
