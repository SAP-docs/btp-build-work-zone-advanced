# Edit the ID of a Content Provider

Administrators of different landscapes may need to edit the ID of a content provider for transport purposes.



> ### Note:  



## Overview

When transporting content between landscapes \(Dev, Test, Prod\), the ID of a specific content provider must be identical in all landscapes. Edit the ID in the target landscape only if you must correct it to be identical to the value in the source landscape.

> ### Note:  
> If you have already added content to your subaccount from this provider before performing the import, changing its ID removes all the added content.



<a name="loio28d9ffac644940048f6cb92e14ef2b96__section_mzy_mx5_pmb"/>

## Procedure

Edit the ID of a content provider only when you must do so for transport purposes.

1.  In the Channel Manager of the target lanscape, click :pencil2: .

    The content of the ID field is disabled, and there is a lock icon \(:lock:\) to the right of it.

2.  Click the lock icon.

    The field is enabled for editing.

3.  Modify the ID as necessary.

4.  Save your change.


You can now perform the import to the target landscape.
