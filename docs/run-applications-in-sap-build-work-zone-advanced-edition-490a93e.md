# Run Applications in SAP Build Work Zone, Advanced Edition

Additonal steps are required to run HTML5 applications in SAP Build Work Zone, advanced edition.



After exposing the HTML5 applications to SAP Build Work Zone, advanced edition and deploying them to the same subaccount as the SAP Build Work Zone, advanced editionsubscription, you need to perform additional steps in the administration environment .

For more information, see [HTML5 Apps Content Provider](https://help.sap.com/docs/WZ_STD/8c8e1958338140699bd4811b37b82ece/ad2103e2fde342878bcf41a8ae8a0bd8.html).
