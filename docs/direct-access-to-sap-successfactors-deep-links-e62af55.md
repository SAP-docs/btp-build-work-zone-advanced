# Direct Access to SAP SuccessFactors Deep Links

Create a destination in the SAP BTP cockpit for navigation by specifying the web hose URL of the SAP SuccessFactors system, without authentication.



In the SAP BTP cockpit, under *Destinations*, create a new runtime destination. These are the properties you'll need to enter:
