# Site Announcements

Create an announcement to communicate important news and events on all screens in your site.

The site announcement appears at the top of the screen and is used mainly to convey messages that you want people to notice.

To configure the site announcement:

1.  Open the Administration Console, and navigate to *Theming & Branding* \> *Site Announcements*.

2.  Create an announcement and style it using the text box provided.

3.  Use the toggle when you want the announcement to be visible - all users in the company will see the announcement.

4.  The announcement appears on a blue background. If it's a very important message or a warning, you can select the option to show the message in a warning or important style and the background color changes to orange.
