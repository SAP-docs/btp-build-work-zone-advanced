# Using the Joule Work Mobile App

The Joule Work mobile application is the native entry point to all relevant business processes, data, and content on mobile.



The Joule Work mobile app enables you to access your responsive business apps along with other content and critical business information. This includes notifications and consolidated views on tasks, approval workflows, and business information. The Joule Work mobile app doesn't offer offline capabilities and it requires internet access to exchange data.

To start using the Joule Work mobile app, do the following:

> ### Note:  
> You can only access the Joule Work mobile app if the administrator has enabled it for you in the *Site Settings*.

1.  Under your avatar, select *Settings*.

2.  Go to *Joule Work Mobile App* in the side panel.

3.  Scan the QR code to install the mobile application.

4.  *Save* your changes.


For more information about what you can do with the Joule Work mobile app, see [**Joule Work Mobile App – Administration Guide**](https://help.sap.com/docs/joule-work-mobile/user-guide-sap-build-work-zone-setup/mobile-app).
