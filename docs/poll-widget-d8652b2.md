# Poll Widget

Add a Poll widget to increase awareness and visiblility of a poll to your company, area, or workspace.

Users can add or change their vote, view poll results, and see when a poll is due to be closed directly within the widget.

You can add a poll widget to a workpage, area page, or company home page.

To create a poll, you need to go to the *Content* screen and open up the *Decision- Making Tools* option.

When you add the *Polls* widget, from the dialog box, enter a title for the widget and then select the poll you want to expose from the *Content* list and save it.

For more information about how to create a poll, see [How to Use Decision-Making Tools](how-to-use-decision-making-tools-f59c12c.md).
