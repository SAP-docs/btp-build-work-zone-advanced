# About Domains

You can choose the domain that you want to use to expose your site.



In SAP Build Work Zone, advanced edition, you have the following options:

-   Using your own custom domain.

    For more information, see [Set Up a Custom Domain.](https://help.sap.com/docs/build-work-zone-advanced-edition/sap-build-work-zone-advanced-edition/set-up-custom-domain)

-   Using SAP's common super domain - **`workzone-advanced.cloud.sap`** or **`workzone-hr.cloud.sap`**`workzone-advanced.sapcloud.cn` or `workzone-hr.sapcloud.cn`

    For more information, see [Using the Common Super Domain](using-the-common-super-domain-0176e29.md).

-   Using the default `ondemand.com` domain.

-   Using the default `portal.cn40.apps.platform.sapcloud.cn` domain

> ### Note:  
> It’s important that no matter what domain you choose to use, that you have a consistent domain whether it be an `ondemand.com`, `cloud.sap``sapcloud.cn`, or your own custom domain.
