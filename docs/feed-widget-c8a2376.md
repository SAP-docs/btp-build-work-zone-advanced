# Feed Widget

Add a feed widget to display real time updates of activity shared by you and your workspace colleagues.

When you add a feed widget to a workpage, it allows you to display real time activities in one place. You can only have one feed widget per workpage. If you want to include more than one feed in a workspace, you can do so by adding a new feed on a different workpage. Workspace members can engage with the feed activities by posting updates, liking, and replying to them on the workspace workpages.

You can set the following details for an activities feed:

-   **Select feed type:** Select the type of activity to appear in the feed \(e.g., content updates, forum updates, workspace status, or all activities\).

-   **Select layout:** Display your feed with the standard or emphasized font size and appearance.

-   **Widget title:** Enter a name for the feed activity or accept the default name provided in the selection for feed type.

-   **Maximum number of items:** Click and drag the scale slider to set a maximum between 1 and 25 feed items to display.

-   **Filter by tag:** Enter text that refines what appears in an activity feed; one or more tags are allowed, comma-separated.
